# 安全与隐私

## 当前原型

- 账本由浏览器的 `localStorage` 保存。应用同源的脚本及能访问该浏览器配置的人可能读取这些数据。
- 小票文件只在浏览器本地预览。录入窗口关闭时释放临时图片链接。页面接受 PNG、JPEG 和 WebP，文件限制为 8 MiB。
- 查账和文字录入使用本地规则。页面的内容安全策略禁止网络请求、外部脚本和表单导航，并允许同源静态资源及本地小票预览。
- 从浏览器存储恢复时校验流水与预算；商户、备注和日期等显示内容经过转义。浏览器存储中不符合结构的条目会在加载时跳过。

测试或提交问题时请使用示例账本，避免附上真实小票、账单、浏览器存储导出或访问凭据。

## 报告安全问题

请优先使用仓库 **Security → Report a vulnerability** 私下联系维护者，前提是仓库启用了该入口。也可以通过你已有的私下联系方式联系维护者。报告请包含受影响的版本、影响范围、预期行为及使用示例数据观察到的现象。请在维护者处理前避免在公开议题里披露敏感细节。

## 范围

本次审查针对前端原型、内嵌图片和浏览器数据流。若后续接入模型、OCR、同步或账户体系，需要另行审查服务端密钥、身份验证、访问控制、数据留存与依赖供应链。
